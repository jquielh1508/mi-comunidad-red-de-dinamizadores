# Red de Dinamizadores · Banco de Estrategias y Recursos

> **Propósito:** Queremos crear **un espacio abierto de intercambio y memoria colectiva** para que **cualquier dinamizador o dinamizadora** pueda **encontrar, adaptar y compartir estrategias y recursos para capacitaciones, círculos de lectura, tardes de películas, días internacionales y otras actividades comunitarias sin empezar de cero**.

Este repositorio funciona como la infraestructura base de nuestra comunidad de práctica: aquí guardamos cómo nos organizamos, los materiales probados en nuestras actividades y los aprendizajes de nuestros encuentros para que cualquiera pueda sumarse o continuar esta red.

---

## 🚀 Cómo empezar a participar en 3 pasos

1. **Explora y reutiliza:** Entra a [`recursos/`](recursos/) y descarga una guía o plantilla para tu próxima capacitación, círculo de lectura, cineforo o jornada por un día internacional.
2. **Comparte o pide ideas:** Abre un **[Issue](../../issues)** para pedir recomendaciones (ej. *"¿Qué película recomiendan para trabajar empatía?"* o *"Ideas para el Día Internacional de..."*) o para contar cómo te fue con una actividad.
3. **Convierte tu experiencia en un recurso (*Flow → Stock*):** Si realizaste una actividad que funcionó bien, documéntala usando [`recursos/plantilla-ficha-actividad.md`](recursos/guia-actividades-socioculturales-y-tic.md) y súbela mediante un Pull Request (o déjala en un Issue para que el equipo editor la integre).
